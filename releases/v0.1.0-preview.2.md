# v0.1.0-preview.2

按项目负责人 2026-10-15 的决定，移除地上/地下 PipeRun 判断。命令不再读取地下标识；规则引擎从 Spec 映射开始评估，不再因为地下标识为 true 或未知而提前返回 `NOT_APPLICABLE` 或 `REVIEW`。

配置和 CSV 演示中的地下标识字段已移除。默认仍为 `DryRun=true`，不会修改模型；`REVIEW`、`MISMATCH` 等状态仍不进入写入事务。

上一份现场报告扫描到 221 条 Working Set PipeRun，但全部操作温度为空，且 163 条使用尚未映射的 Spec。此版本解除地下标识造成的统一阻断，但仍需在目标 Plant 核对温度读取及补充 Spec/保温映射。扫描范围仍为活动 Working Set，不保证覆盖整个项目。

部署时替换全部 DLL 和整个 `config` 目录，并重启 S3D。先运行 DryRun 并核对新报告，再决定是否启用写入。
